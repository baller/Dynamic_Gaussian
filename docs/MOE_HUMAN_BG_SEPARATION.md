# 人体/背景区分机制说明（无显式 Mask）

## 问题

项目**没有**提供人体 mask 或背景 mask，人体与背景的区分是如何实现的？

---

## 答案概览

人体/背景区分是**通过可学习路由器（Router）从图像特征中自发学出来的**，而不是靠给定的 mask。训练时只用「重建损失 + MoE 辅助损失」，路由器学会把不同区域分给不同专家；专家 0 约定为「背景」、专家 1 为「人体」，只是命名，模型可从数据中自己学到谁管背景、谁管人体。

---

## 1. 路由器在做什么

### 1.1 输入与输出

- **输入**：图像相关特征（无 mask）
  - **CNN MoE**：UNet 图像特征 `[B, C, H, W]`
  - **Transformer MoE**：DINO 特征 + 深度嵌入，在 patch 维度上为 `[B, N, 1088]`
- **输出**：每个位置（像素或 patch）对「专家 0 / 专家 1」的软权重  
  - `router_weights[:, 0]`：专家 0 权重（约定为背景）
  - `router_weights[:, 1]`：专家 1 权重（约定为人体）  
  二者在通道维做 softmax，和为 1。

也就是说：**路由器根据外观/深度等特征，为每个位置生成「更像背景」还是「更像人体」的软分配**，相当于在学「伪 mask」，但完全来自数据与损失，没有人工标注的 mask。

### 1.2 路由器实现形态

| 模式 | 路由器输入 | 代码位置 |
|------|------------|----------|
| CNN MoE basic | UNet 特征 | `moe_router.py` → `MoERouter` |
| CNN MoE depth_aware | UNet 特征 + 深度图（含深度梯度） | `moe_router.py` → `DepthAwareMoERouter` |
| Transformer MoE | DINO 特征 + 深度嵌入（逐 patch） | `moe_transformer.py` → `MoERouter` |

其中 **depth_aware** 会用深度+梯度，帮助利用「人物边界 ≈ 深度不连续」这类先验，但仍没有显式人体/背景 mask。

---

## 2. 模型如何学会「人体 vs 背景」

没有任何人体/背景监督，区分完全由以下机制驱动。

### 2.1 主监督：渲染重建

- 损失：`L_render = 0.8 * L1 + 0.2 * (1 - SSIM)`，在**最终融合渲染图**上算。
- 融合方式：  
  `final = shared_weight * shared_expert(x) + (1 - shared_weight) * (w0 * expert0(x) + w1 * expert1(x))`  
  其中 `w0, w1` 就是路由权重。
- 若路由乱分（该给人体的给背景专家、该给背景的给人休专家），重建会变差，梯度会推着路由器与专家一起改，直到「谁管哪块区域」能让重建最好。  
  因此，**重建损失本身就在隐式地要求路由器把「外观/几何不同的区域」分给不同专家**，人体/背景自然落在不同专家上。

### 2.2 稀疏性损失（Sparsity）

- 形式：对 `router_weights` 的熵求平均，熵越小越好。
- 效果：鼓励每个位置的权重接近 (1,0) 或 (0,1)，即**要么 mainly 背景专家、要么 mainly 人体专家**，形成清晰软分割，而不是到处 0.5/0.5。
- 不提供 mask，但迫使路由器在「背景/人体」二选一上做决定，从而更像「学出一个伪 mask」。

### 2.3 时序一致性损失（Temporal）

- 在「当前帧 & 上一帧都被判为背景」的区域上，约束当前帧背景权重与上一帧接近。
- 效果：**静态背景**的路由在时间上要稳；**人体/运动区域**允许变。  
  模型会逐渐学会：稳定的区域 → 专家 0（背景），变化的区域 → 专家 1（人体），从而在无 mask 的情况下把「动/静」与「人/背景」对应起来。

### 2.4 分离损失（Separation）

- 惩罚两个专家预测的高斯参数过于相似（scale、opacity 等）。
- 效果：推动**专家 0 和专家 1 学不同模式**（一个偏背景、一个偏人体），路由器再根据特征把不同区域分给不同专家，形成分工。

### 2.5 平衡损失（Balance）

- 约束「专家 0 占比」不要过小或过大（例如靠近 `target_bg_ratio`）。
- 效果：避免退化成「全部由一个专家负责」，保证两个专家都有事做，有利于学到「一个偏背景、一个偏人体」的分工。

---

## 3. 「专家 0=背景、专家 1=人体」从哪来

- 代码里仅通过 `expert_names = ['bg', 'human']` 这类**命名**把专家 0 当作背景、专家 1 当作人体。
- 模型**没有**收到「这块是人体、那块是背景」的标签；它只是被损失驱动，去学「怎样分配两个专家能让重建最好 + 稀疏 + 时序稳 + 专家有差异」。
- 典型学到的结果会变成：一个专家主要负责静态、大块、远的部分（背景），另一个负责运动、小目标、近的部分（人体），对应到「背景 / 人体」的语义，是**从数据与任务中涌现的**，而不是由 mask 定义的。

---

## 4. 可选：用深度辅助（仍无 mask）

当使用 **DepthAwareMoERouter** 时：

- 输入 = 图像特征 + 深度图 + 深度梯度（Sobel）。
- 深度梯度大 ≈ 前景/背景或人体边界；路由器可学「深度不连续 → 多给人休专家」等模式。
- 依然**没有**人体/背景 mask，只是多了一个几何线索，让「谁管前景、谁管背景」学得更稳。

---

## 5. 简短总结

| 问题 | 答案 |
|------|------|
| 有人体/背景 mask 吗？ | **没有**，训练/推理都不需要。 |
| 谁在决定「这是人体还是背景」？ | **可学习路由器**，根据图像（和可选深度）特征为每个位置输出软权重。 |
| 路由器凭什么学对？ | **重建损失**提供主监督；**稀疏、时序、分离、平衡**等损失一起，促使路由器把「静/大/远」和「动/小/近」分给不同专家，从而对应到背景/人体。 |
| 「专家 0=背景、专家 1=人体」是硬编码吗？ | 只是命名习惯；实际谁管背景、谁管人体是**从数据里学出来的**。 |

因此，**人体/背景的区分完全来自「路由 + 专家 + 多种损失」的联合学习，没有也不依赖显式的人体或背景 mask。**
