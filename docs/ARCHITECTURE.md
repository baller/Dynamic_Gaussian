## 模块参数统计 (当前配置)

| 模块 | 参数量 | 可训练 | 显存估计 |
|------|--------|--------|----------|
| DA3-BASE (DINOv2-B) | ~86M | ❌ 冻结 | ~0.4GB 参数 |
| DA3 前向激活值 | - | - | ~2-3GB |
| Feature Adapter | ~2M | ✅ | ~10MB |
| Depth Fusion | ~0.5M | ✅ | ~50MB |
| Transformer+MoE | ~1.5M | ✅ | ~100MB |
| 输出头 | ~0.1M | ✅ | ~5MB |
| **总计** | **~90M** | **~4M 可训练** | **~4-6GB** |

## 关键创新点

### 1. DA3 替代 RAFT
- **原方案**: RAFT-Stereo 立体匹配 → 视差 → 深度
- **新方案**: Depth Anything V3 单目深度估计 + 特征提取
- **优势**: 更强的泛化能力，弱纹理区域表现更好

### 2. 深度融合模块
- 融合左右视图的单目深度
- Cross-View Attention 增强一致性
- Scale Regressor 解决相对深度的尺度问题

### 3. Transformer + MoE
- Window Self-Attention 处理局部上下文
- MoE MLP 让不同专家处理不同材质/纹理
- 4x 下采样减少计算量

### 4. 动态高斯分配 (规划中)
- 多层高斯假设
- 基于 opacity 的软剪枝
- 纹理复杂度引导的分配
